🗺️ Map Element Geographic Positioning Test

📍 How It Works

Three projection methods ensure accurate positioning:

  • Equirectangular (default) - Simple linear mapping, works great for standard world maps
  • Mercator - Better for navigation maps, accounts for latitude distortion
  • Calibrated - Uses reference points for perfect accuracy (see code example)

Location labels show: City, State (if US), Country - updates automatically when dots are added

Data format: {lat, lon, city, state, country}
